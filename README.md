# TruthGraph benchmark evidence

Raw, unedited evidence behind performance claims made about [TruthGraph](https://truthgraph.weeyuga.com). Each folder is one comparison. It holds the agent session logs exactly as the agent wrote them, a standard-library script that recomputes the numbers, and SHA-256 hashes of every file. Screen recordings are attached to the release with the same name as the folder.

| Folder | What it shows |
| --- | --- |
| [`2026-10-25-weeyugaweb-request-id`](2026-10-25-weeyugaweb-request-id/) | One planning task on a private codebase, Codex with and without TruthGraph: 28.9% fewer total tokens, 51 s faster. One run each; read the caveats. |

The logs come straight from the agent. Nothing has been trimmed, redacted or reformatted.
